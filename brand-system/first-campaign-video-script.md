## 🎙️ 5. Seni Bina Audio: Edge-TTS `ms-MY-YasminNeural`

Suara latar (Voiceover) dijana secara automatik menggunakan enjin **Microsoft Edge Neural TTS** dengan watak suara tempatan Malaysia `ms-MY-YasminNeural`. Tonasi adalah ceria, moden (*rojak KL street-slang*), bersemangat, dan tidak kedengaran seperti robot korporat.

### A. Parameter Konfigurasi Edge-TTS
* **Voice ID**: `ms-MY-YasminNeural`
* **Speed / Rate**: `+14%` (Laju, bertenaga, mengikut tempo video pendek FYP).
* **Pitch**: `+2Hz` (Lebih ceria dan mengujakan).
* **Volume**: `+0%` (Dinormalkan ke standard penyiaran).

### B. Skrip Penuh SSML (Speech Synthesis Markup Language)
Simpan kod ini sebagai `first-campaign-voiceover.ssml`:

```xml

  <voice name="ms-MY-YasminNeural">
    <prosody rate="+14%" pitch="+2Hz">
      <!-- 00:00.0 - 00:02.0 [Hook] -->
      <emphasis level="strong">DOH NUT PANIC!</emphasis>
      <break time="120ms"/>
      Tengok lelehan gebu ni, terus hilang stress kan?
      <break time="200ms"/>

      <!-- 00:02.0 - 00:04.5 [Knead & Stamp] -->
      Uli sampai kembang,
      <break time="80ms"/>
      tekan acuan sampai <emphasis level="moderate">pop!</emphasis>
      <break time="180ms"/>

      <!-- 00:04.5 - 00:06.5 [Sizzle & Dip] -->
      Goreng garing keemasan,
      <break time="90ms"/>
      lepastu celup sos strawberi tebal-tebal!
      <break time="150ms"/>

      <!-- 00:06.5 - 00:07.5 [Sprinkle] -->
      Tabur sprinkles warna-warni...
      <break time="120ms"/>
      <emphasis level="strong">DOH SEDAP WEI!</emphasis>
      <break time="180ms"/>

      <!-- 00:07.5 - 00:08.8 [Loop Bridge Setup] -->
      So bila hidup kau rasa serabut tu, ingat satu je...
    </prosody>
  </voice>
</speak>
```

### C. Arahan Penjanaan CLI & Skrip Python Autonomi

Jalankan perintah berikut dalam terminal untuk menjana fail audio rasmi:

```bash

         --write-media "G:/Doh-Nut/public/videos/first-campaign-voiceover.mp3"
```

Skrip Python autonomi untuk penjanaan tepat bersama SSML:

```python
# G:\Doh-Nut\scripts\generate_campaign_voiceover.py
import asyncio
import edge_tts

SSML_PATH = r"G:\Doh-Nut\brand-system\first-campaign-voiceover.ssml"
OUTPUT_AUDIO = r"G:\Doh-Nut\public\videos\first-campaign-voiceover.mp3"

async def main():
    with open(SSML_PATH, "r", encoding="utf-8") as f:
        ssml_content = f.read()
    
    communicate = edge_tts.Communicate(text=ssml_content, voice="ms-MY-YasminNeural")
    await communicate.save(OUTPUT_AUDIO)
    print(f"✅ Voiceover audio berjaya dijana di: {OUTPUT_AUDIO}")

if __name__ == "__main__":
    asyncio.run(main())
```

  * Warna: `#07334F`
  * Jarak: `X: 0px, Y: 8px`

## 🎧 8. Reka Bentuk Bunyi & Trek Muzik (Audio Stems & Foley)

Untuk menghasilkan sensasi deria fizikal yang memukau tanpa audio murahan (*royalty-free slop*):

1. **Trek Muzik Latar (BGM Bed)**:
   * **Genre**: Playful Funky Hip-Hop / Nu-Disco Grooves (Tempo: `128 BPM`).
   * **Instrumen**: Slap bass kenyal, drum kick gemuk (*fat 808*), petikan gitar funk bersahaja, dan bunyi *bubble synth pops*.
   * **Mixing Level**: `-16 dBFS` semasa suara latar bercakap; melonjak ke `-8 dBFS` semasa transisi logo.
2. **Lapisan Foley ASMR (Hyper-Realistic Tactile Sounds)**:
   * Setiap aksi visual mempunyai padanan bunyi foley berasingan yang di-pan di bahagian stereo tengah (*center stereo image*).
   * Kesan *high-end sizzle* pada Fasa 03 dinaikkan pada frekuensi `8 kHz - 12 kHz` untuk merangsang tindak balas deria ASMR pendengar fon telinga.
